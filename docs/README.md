# Project Documentation

## Canonical EarthLink API References

Before changing, debugging, testing, or designing any EarthLink reseller API integration, read these two files first:

- `docs/earthlink_reseller_app_api_documentation_v0_7_0.md` — canonical API specification and protocol behavior.
- `docs/earthlink_app_api_poc_v0_6_48.py` — reference Python proof-of-concept for request/payload handling and observed edge cases.

These files are permanent technical reference material, not historical implementation plans. Do not replace API facts with assumptions or invent endpoints/payload semantics when the references already define them.
